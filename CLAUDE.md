# CLAUDE.md — Threshold

Перед любой задачей прочитай:

1. `tech.md` — источник истины по технике: стек, ID, раскладка, контракты, слайсы. Подчиняйся дословно.
2. `docs/threshold-plan.md` — геймдизайн и план версий. Механики сверяй с ним.

Главные правила:

- Нужного контракта нет в `tech.md` → СТОП, блок `CONTRACT GAP` (`tech.md`, раздел 13). Имена, ID и типы не выдумывай.
- Один слайс за заход, по `tech.md`, раздел 15. Слайс закрыт только по Definition of Done.
- `./gradlew` на этой машине не запускай: не хватает памяти. Сборка и тесты идут только в GitHub Actions. Чтобы проверить код: push, потом `gh run watch`.
- Проверка в игре: `scripts/deploy.sh`, потом смотри `build/deploy/latest.log`. Скриншот телефона: `adb -s "$THRESHOLD_ADB" exec-out screencap -p > build/deploy/screen.png`.
- `adb` только с `-s 100.98.166.61:5555` (Galaxy A22). Второе устройство в `adb` (SaluteTV) не трогать.
- Миры, аккаунты, настройки лаунчера и сети на телефоне не менять без прямой просьбы владельца.

Коммиты:

- Формат и язык — `tech.md`, раздел 12.
- Никаких `Co-Authored-By`, `Signed-off-by`, «Generated with» и других строк об авторстве. Автор — только владелец проекта из локального `git config`.
- Коллабораторов в репозиторий не добавлять.
